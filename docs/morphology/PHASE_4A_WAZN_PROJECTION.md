# Phase 4A — Wazn Projection

طبقة مستقلة تُسقط الجذر المقبول (RootCandidate) على بنية السطح الصرفية
وتُنتج `WaznProjection`. لا تستخرج جذرًا، ولا تستنتج بابًا، ولا تولّد مصدرًا أو
مشتقات.

الموقع: `pipeline/p4_wazn/`. الـcatalog: `data/wazn/wazn_catalog.json`.

---

## 1. مدخل المرحلة

المدخل الوحيد المعتمد: `RootCandidate` (P3).

```python
from pipeline.p4_wazn import project_wazn
projection = project_wazn(root_candidate)
```

المرافقات المرخّصة تُقرأ من الكائن نفسه: `host_surface` (= analyzed_host)،
`canonical_root`، `root_profile`، `evidence_ids`، `trace_ids`، `residual_codes`.
يمكن تمرير `normalized_host=` صراحةً، وإلا يُشتق من `analyzed_host` عبر
`normalize_for_wazn` (توحيد الهمزة + توسيع الشدة فقط — **بلا** منطق أداة التعريف).

Phase 4A **لا** تفعل: استدعاء HR2S، إعادة تحليل السطح لاستخراج الجذر، تعديل
`canonical_root`، استعادة حرف جذري بالتخمين، قراءة السطح الأصلي عندما يتوفّر
`analyzed_host`، أو إعادة إدخال أداة التعريف/الضمائر المفصولة.

## 2. مخرج المرحلة

`WaznProjection` (frozen، قابل للتسلسل JSON). أهم الحقول:

| الحقل | المعنى |
|------|--------|
| `directive` | `ACCEPT` \| `DEFER` \| `BLOCK` |
| `stage_state` | `COMPLETED` \| `DEFERRED` \| `BLOCKED` \| `NOT_OPENED` |
| `selected_wazn` | الوزن المختار إن ثبت وحيدًا، وإلا `None` |
| `candidate_awzan` | الأوزان المرشّحة |
| `root_slot_alignment` | محاذاة ف/ع/ل(/ل2) بالسطح |
| `ziyadah_slots` / `weak_operations` | الزيادات والعمليات المرخّصة |
| `inflectional_suffixes` | اللواحق التصريفية المفصولة عن الوزن |
| `canonical_root` | منقول كما هو من RootCandidate (لا يُعدَّل) |

## 3. الفرق بين الجذر والوزن

- **الجذر** (RootCandidate): هوية الحروف الأصلية ورتبتها (ف/ع/ل). يُنتَج في P3 من
  HR2S. Phase 4A تستهلكه ولا تعيد إنتاجه.
- **الوزن** (Phase 4A): الهندسة التي تُسقط الجذر على السطح — أين وقعت خانات الجذر،
  وما الزيادات، وما العمليات (إدغام/تضعيف). الوزن لا يغيّر الجذر أبدًا.

## 4. الفرق بين الوزن الاشتقاقي والتصريف

الوزن الاشتقاقي (مثل `فَعَلَ`) بنية الكلمة الصرفية. اللواحق التصريفية (تاء التأنيث
الساكنة `تْ`، علامات الإسناد، الضمائر) خارج أصل الوزن. المخرج يفصلها في
`inflectional_suffixes` ولا يخلطها بالمحاذاة الجذرية.

مثال: `تَرَكَتْ` → الوزن الاشتقاقي `فَعَلَ` (ت‑ر‑ك)، و`تْ` لاحقة تصريفية.

## 5. Ziyadah Audit

الزيادة لا تُقبل إلا إذا: (1) موقعها في تعريف الوزن، (2) هويتها توافق الحرف
المطلوب، (3) لا تحل محل حرف جذري بلا عقد، (4) لا تنتج ترتيبًا مكسورًا. كون الحرف
من «سألتمونيها» لا يجعله زائدًا في كل موضع — الموقع يحسمه قالب الوزن. النتائج:
`ACCEPT` (كل الزيادات مرخّصة) / `DEFER` (تفسيرات متعددة/تأنيث اسمي غير معقود) /
`BLOCK` (زيادة غير مرخّصة أو ترتيب مستحيل).

## 6. الشدة

الشدة تُوسَّع (`Cّ` → `Cْ + C`) قبل المحاذاة. قد يكون أحد شقّيها:
- **تكرار حرف جذري (مضاعف):** `مَدَّ` = `مَدْدَ`، الدالان جذريتان، الوزن `فَعَلَ`
  بعملية `إدغام المضاعف`. الجذر يبقى `م د د`.
- **تضعيف عين الوزن:** `عَلَّمَ` = `عَلْلَمَ`، اللام الأولى عين الجذر، والثانية زيادة
  (تضعيف)، الوزن `فَعَّل`. الجذر يبقى `ع ل م` (لا `ع ل ل م`).

القالب يحسم أيّ الحالتين، والأوزان التي لا ترخّص الإدغام لا تطابق المضاعف المُدغَم
(يمنع تعدّد المطابقة الزائف بين `فَعَلَ` و`فَعْل`).

## 7. الهمزة

هوية الجذر المعتمدة `ء`. صور الهمزة السطحية (`أ إ ؤ ئ آ`) تُطبَّع إلى `ء` فتُقابلها
allographs فقط. مثال: `قَرَأَ` جذره `ق ر ء` ووزنه `فَعَلَ`؛ يُمنع إخراج `ق ر أ`
جذرًا قانونيًا.

## 8. الإعلال

Phase 4A لا تستعيد جذرًا مجهولًا. `ا/ى` في السطح لا تُقابلان هوية جذرية مباشرة،
والواو/الياء الجذريتان تُؤخذان من RootCandidate فقط، والحذف/القلب يحتاج operation
مرخّصة. لذلك الحالات ذات الجذر غير المحلول (`قَالَ`, `دَعَا`, `وَقَى`, `قُلْ`) تصل
بـ RootCandidate = DEFER، فتكون Wazn = `DEFER / NOT_OPENED` بلا أي عملية إعلال.

## 9. ACCEPT / DEFER / BLOCK

- **ACCEPT:** RootCandidate=ACCEPT، وكل الحروف الجذرية محاذاة، وكل الزيادات
  والعمليات مرخّصة، ووزن واحد مثبت فقط (لا ثانٍ مكافئ)، ولا residual قادح.
- **DEFER:** تعدد الأوزان، أو تعذّر الفصل بين زيادة وأصل، أو حاجة إلى معلومة باب/معجم،
  أو تأنيث اسمي غير معقود، أو زيادة بنيوية غير مرخّصة لكنها محتملة.
- **BLOCK:** ترتيب الجذر لا يُحفَظ، أو غياب حرف جذري بلا operation، أو حرف زائد غير
  من الزيادة، أو arity غير مدعوم.

## 10. لماذا لا تختار المرحلة الباب؟

Phase 4A تعرف الهندسة فقط (root‑to‑surface geometry، الأوزان المرخّصة، الزيادة،
المحاذاة، العمليات السطحية). لا تعرف: باب الفعل، المضارع المقابل، المصدر، اسم
الفاعل/المفعول النهائي، الإعراب، أو المعنى. اختيار الباب (`فَعَلَ يَفْعُلُ/يَفْعِلُ/
يَفْعَلُ`) ملك Phase 4B. الوزن `فَعَلَ` يُنتَج دون تحديد بابه.

## 11. الرتابة

```
RootCandidate BLOCK  → Wazn BLOCK / NOT_OPENED     (لا alignment)
RootCandidate DEFER  → Wazn DEFER / NOT_OPENED     (لا alignment)
RootCandidate ACCEPT → Wazn ACCEPT / DEFER / BLOCK
```

يُمنع: `Root DEFER → Wazn ACCEPT` و`Root BLOCK → Wazn ACCEPT/DEFER`.

## 12. حالات NOT_OPENED

عند RootCandidate = DEFER/BLOCK لا يُفتح alignment، ويُنتَج مخرج صريح:
`selected_wazn=None`، `candidate_awzan=()`، `stage_state=NOT_OPENED`، مع residual
(`defer:wazn:root_candidate_not_resolved` أو `block:wazn:root_candidate_blocked`)،
وحفظ evidence/trace/residuals القادمة من RootCandidate.

## 13. أخطاء العقد

`WaznProjectionContractError` (فشل صريح، لا BLOCK صامت) عند: ACCEPT بلا جذر،
`arity` غير مدعوم، `selected_wazn` خارج المرشّحين، ACCEPT بأكثر من وزن متساوٍ،
ACCEPT بخانة جذرية غير محلولة، ACCEPT بهوية `ا/ى`، محاذاة تكسر ترتيب الجذر،
schema catalog غير صالحة، أو directive غير معروفة.
