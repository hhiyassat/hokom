# طلب تصديق مالك — ولادة المصدر المعياري (تمهيد الجولة 16)

بعد إعداد نموذج التزويد، يُطلب من المالك صراحةً:

1. هل يعتمد `KEEP_COMPOSITE` أم يختار primary domain؟  `PRIMARY = KEEP_COMPOSITE | PICK_ONE`
2. ما المصدر/المصادر المعيارية المزوَّدة؟ (لكل مصدر الحقول الخمسة):
   - `MIRATH_RELATED_DOMAIN_CANDIDATE` (rank 1):
     - AUTHORITY = ...
     - TEXT = ...
     - SCOPE = ...
     - EVIDENCE = ...
     - LINK_LICENSE_TO_DOMAIN_OR_FACTUAL_CLAIM = ...
   - `QADA_RELATED_DOMAIN_CANDIDATE` (rank 2):
     - AUTHORITY = ...
     - TEXT = ...
     - SCOPE = ...
     - EVIDENCE = ...
     - LINK_LICENSE_TO_DOMAIN_OR_FACTUAL_CLAIM = ...
   - `TURKAH_RIGHTS_DOMAIN_CANDIDATE` (rank 3):
     - AUTHORITY = ...
     - TEXT = ...
     - SCOPE = ...
     - EVIDENCE = ...
     - LINK_LICENSE_TO_DOMAIN_OR_FACTUAL_CLAIM = ...
   - `SUKNA_OR_POSSESSION_DOMAIN_CANDIDATE` (rank 4):
     - AUTHORITY = ...
     - TEXT = ...
     - SCOPE = ...
     - EVIDENCE = ...
     - LINK_LICENSE_TO_DOMAIN_OR_FACTUAL_CLAIM = ...
3. هل يسمح بولادة `NORMATIVE_SOURCE`؟  `ALLOW_NORMATIVE_SOURCE_BIRTH = YES | NO`
4. النطاق؟  `SCOPE = THIS_NAZILA_ONLY | GENERAL_RULE`

*حتى يصل التصديق الكامل بالحقول الخمسة: NORMATIVE_SOURCE_BORN = NO · لا حكم/مناط/تنزيل/جواب.*
